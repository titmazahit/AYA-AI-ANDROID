# Ая — Android starter

Это минимальный стартовый проект для Android-приложения Аи.

## Что уже есть
- Kotlin Activity и собственный Canvas View.
- Временная процедурная заглушка персонажа: покачивание, моргание, реакция на касания.
- Базовая конфигурация Gradle.
- GitHub Actions workflow для сборки debug APK в облаке.

## Важно
Нарисованный персонаж — техническая заглушка, не утверждённый мастер-арт и не Live2D.
Здесь пока нет голосового управления, локальной модели ИИ, сетевого ИИ, памяти и режима поверх других приложений.

## Сборка APK через GitHub с телефона
1. Распакуйте архив.
2. Загрузите всё содержимое папки проекта в корень репозитория `titmazahit/AYA-AI-ANDROID` через GitHub в браузере или приложение.
3. Откройте вкладку **Actions** репозитория.
4. Выберите **Build AYA APK** и нажмите **Run workflow** (или дождитесь сборки после push).
5. Откройте завершённый запуск workflow и скачайте artifact `AYA-debug-apk`.
6. Распакуйте artifact и установите `app-debug.apk` на телефон. При необходимости разрешите установку из этого источника.

## Параметры
- applicationId: `com.titmazahit.aya`
- minSdk: 26
- compileSdk: 36
- targetSdk: 35
- Java/Kotlin target: 17
- Android Gradle Plugin: 8.13.2
- Gradle: 8.13

Если GitHub предложит загрузить файлы по одному, сохраните структуру каталогов, особенно `.github/workflows/build-apk.yml`.
